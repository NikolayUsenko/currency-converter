# Конвертер валют

Кроссплатформенное приложение на Qt (C++17) для конвертации валют
по курсам ЦБ РФ. Сквозной проект по дисциплине
«Основы кроссплатформенного программирования».

## Требования
- Qt 5.15 LTS или Qt 6.x, Qt Creator
- Компилятор GCC 9+ / MSVC 2019+ / Clang 10+

## Сборка и запуск
1. Откройте `CurrencyConverter.pro` в Qt Creator.
2. Выберите комплект (Kit), нажмите «Сборка» → «Запуск» (Ctrl+R).
